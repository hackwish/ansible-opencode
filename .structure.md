# ansible-opencode

## Overview

This directory contains the Ansible role for installing Opencode, a command-line interface for interacting with OpenAI API. It supports installation on:

- Linux systems (Ubuntu/Debian-based, Fedora/RHEL-based) via Node.js package manager
- macOS via Homebrew

## Role Structure

The role is organized into the following subdirectories:

- `tasks/` - Main task files for each platform:
  - `main.yml` - Main entry point that imports platform-specific tasks
  - `debian.yml` - Ubuntu/Debian/Linux Mint tasks (Node.js installation)
  - `redhat.yml` - Fedora/RHEL/CentOS tasks (Node.js installation)
  - `darwin.yml` - macOS tasks (Homebrew installation)

- `defaults/main.yml` - Default role variables
- `vars/linux.yml` - Platform-specific variables
- `meta/main.yml` - Role metadata
- `tests/` - Test configuration files
  - `inventory` - Test inventory file
  - `test.yml` - Test playbook

## Usage

To install Opencode:

1. For Debian/Ubuntu-based systems:
```bash
ansible-playbook -i inventory site.yml
```

2. For Fedora/RHEL-based systems:
```bash
ansible-playbook -i inventory site.yml
```

3. For macOS:
```bash
ansible-playbook -i inventory site.yml
```

## Testing

To run the included tests:

```bash
ansible-playbook -i tests/inventory tests/test.yml
```
